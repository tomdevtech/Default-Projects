# Changelog

## 0.1.0

- Template editor: define a title and a structure of files, folders and content.
- Sidebar view with all templates; create, edit and delete directly from the list.
- Commands: `New Template...`, `Create Project from Template...`, `Edit Template...`, `Delete Template...`.
- Built-in `Create Python Project` command.
- `{{name}}` placeholder in file contents.
- Safety: existing folders are never overwritten; template paths cannot leave the project folder.
